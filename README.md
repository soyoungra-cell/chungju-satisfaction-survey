# 부모만족도 조사 도구 — 받으신 분을 위한 안내서

어린이집 부모만족도 조사를 **링크로 보내고 → 응답지를 메일로 받고 → 결과지를 자동으로 완성**하는 도구입니다.
받으신 분이 **자기 어린이집에 맞게 고쳐서 자기 이름으로 배포**할 수 있게 만들었습니다.

---

## 1. 이 도구가 하는 일

```
① 링크 만들기        원장님이 어린이집 이름·받을 메일을 넣으면 링크가 생김
        ↓
② 부모님이 체크       카톡으로 받은 링크를 열어 15문항 체크 (3분, 무기명)
        ↓
③ 응답지 PDF 도착     제출하면 응답지 PDF가 원장님 메일로 자동 전송
        ↓
④ 결과지 자동 완성    메일에 온 PDF들을 결과 화면에 올리면 표·그래프가 완성
```

**결과지는 어린이집 평가·운영위원회에 그대로 낼 수 있는 A4 1장**으로 인쇄됩니다.

---

## 2. 파일이 하는 일 (이것만 알면 됩니다)

| 파일 | 하는 일 | 고쳐도 되나요? |
|---|---|---|
| **config.js** | 문항·영역·색·비밀번호·인사말 | ⭐ **여기만 고치면 대부분 해결됩니다** |
| index.html | 링크 만들기 화면 + 부모님 설문 화면 | 모양을 크게 바꿀 때만 |
| result.html | 결과 화면 (PDF 올리기 + 결과지) | 결과지 모양을 바꿀 때만 |
| api/send.js | 응답지를 메일로 보내는 부분 | 거의 안 건드립니다 |

## 4. 처음 한 번만 하는 준비

### (1) 그냥 쓰기 — 준비 0분
아무것도 설정하지 않아도 **바로 쓸 수 있습니다.**
다만 이 경우 부모님이 제출하면 **PDF가 부모님 기기에 저장**되고,
부모님이 그 파일을 원장님께 직접 보내주셔야 합니다.

### (2) 메일 자동 발송까지 쓰기 — 준비 5분 (권장)
부모님이 제출하면 응답지가 **자동으로** 원장님 메일로 옵니다. 회수율이 훨씬 좋습니다.

1. [브레보(Brevo)](https://www.brevo.com) 에 무료 가입합니다. (하루 300통 무료)
2. 로그인 후 **SMTP & API → API Keys → Generate a new API key** 를 눌러 열쇠를 만듭니다.
3. **Senders** 메뉴에서 본인 메일 주소를 등록하고 인증 메일을 확인합니다.
4. 배포한 곳(Vercel)의 **Settings → Environment Variables** 에 아래 3개를 넣습니다.

| 이름 | 값 |
|---|---|
| `BREVO_API_KEY` | 2번에서 만든 열쇠 |
| `FROM_EMAIL` | 3번에서 인증한 메일 주소 |
| `FROM_NAME` | 부모만족도 조사 |

5. 다시 배포(Redeploy)하면 끝입니다.

> 💡 이 과정도 클로드에게 **"브레보 설정하는 것 좀 도와줘"** 하시면 하나씩 안내해 줍니다.

## 5. 꼭 알아두실 것 ⚠️

- **한메일(@hanmail.net)로는 응답 메일이 도착하지 않습니다.** (카카오가 발송 서버를 차단합니다)
  지메일이나 네이버 주소를 쓰세요. 앱에서도 한메일은 입력이 막혀 있습니다.
- **모인 결과는 그 컴퓨터의 그 브라우저에만 저장됩니다.**
  인터넷 기록을 지우거나 다른 컴퓨터에서 열면 보이지 않습니다.
  조사가 끝나면 결과 화면의 **💾 백업 내보내기**를 눌러 파일로 보관하세요.
- **원본 응답지 PDF는 메일함에 그대로 남아 있으니** 백업을 깜빡해도 다시 올리면 됩니다.
- 결과 화면 비밀번호는 간단한 잠금장치입니다. 응답 내용은 무기명이지만,
  **결과 화면 주소는 부모님께 알려주지 마세요.**

## 6. 자주 묻는 것

**Q. 부모님이 PDF를 두 번 보내셨어요.**
괜찮습니다. 같은 응답은 자동으로 걸러집니다. (응답마다 번호가 붙어 있습니다)

**Q. PDF를 올렸는데 "이 조사서의 응답지가 아니에요" 라고 나옵니다.**
다른 파일이거나, 부모님이 화면을 캡처해서 만든 PDF일 수 있습니다.
결과 화면 아래쪽 **"코드로 직접 넣기"** 칸에 응답 코드를 붙여넣어도 집계됩니다.

**Q. 문항을 바꾸면 이미 받은 응답은 어떻게 되나요?**
이미 받은 응답은 **응답지에 영역과 문항 수가 함께 들어 있어서** 그대로 집계됩니다.
다만 헷갈리니 **조사를 시작하기 전에 문항을 확정**하시길 권합니다.

**Q. 인쇄하면 글자가 잘려요.**
인쇄 창에서 **용지 A4**, **여백 없음**, **배경 그래픽 켜기**로 맞춰주세요.
